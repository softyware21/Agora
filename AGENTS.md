Read CONTRIBUTING.md before making changes.

Keep repository text, comments, commits, issues, and pull requests in English.
Write plainly and describe actual behavior. Do not invent tests, results, or
development history. Use comments only when they explain something the code does not.

Run offline tests with `python -m unittest discover -s tests -v` after behavior changes.
Do not put account details, credentials, local transcripts, or CLI binaries in Git.
Do not treat model agreement as factual verification.
